Weight is type and space. Not a second sentence.


| Role        | Use                                                                |
| ----------- | ------------------------------------------------------------------ |
| **Display** | The conclusion. Largest type in the section. Must stand alone.     |
| **Support** | Only a fact the display does not contain. One line.                |
| **Fact**    | A number or name. Isolated. Sun Gold or Deep Sea, not a paragraph. |
| **Strip**   | Documentary labels. Small. No verbs.                               |
| **Action**  | One per screen.                                                    |


If the display already said it, delete the support.
