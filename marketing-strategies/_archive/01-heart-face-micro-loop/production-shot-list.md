# Production shot list — Uriel + videographer (Valencia)

**Primary piece:** 70–90s founder hook ([`founder-video-script.md`](founder-video-script.md))  
**Crew:** Uriel (talent) + 1 videographer (+ optional sound if available)  
**Look:** Documentary / private-client honesty — not real-estate brochure. Natural light preferred. No gimbal hero walks unless earned.  
**Formats:** Film **horizontal 16:9** master; crop safe for 9:16 social. Protect the frame: Uriel’s eyes in upper third on A-roll.  
**Budget mode:** Live shoot only what sells trust. Buy stock for generic geography (airport, metro texture, city contrast, nature). See [Live vs stock](#live-vs-stock--cost-cut).

---

## Live vs stock — cost cut

**Rule:** If a stranger must believe *this is our building and our founder*, shoot it. If a stranger only needs a *recognizable place cue*, stock is fine.

| Shot IDs | Live (must shoot) | Why |
|---|---|---|
| **A1–A3** | Uriel A-roll | Face = the whole strategy |
| **B1–B5** | Riba-roja address, plot/structure, plans, walk, build texture | Specific asset — stock will look fake |
| **F1–F2** | Puzol exterior + Uriel there *(if day allows)* | Only *your* proof of delivery |
| Stills | Uriel portraits | LinkedIn / one-pager |

| Shot IDs | Buy stock (cut costs) | Search / brief for buyer |
|---|---|---|
| **C / D airport** | Plane approach, VLC/Manises exterior, airport road | `Valencia airport Manises`, `plane landing Valencia`, dusk OK; **no** generic Dubai/Miami airport |
| **C metro** | Metro platform / train *(optional live if near site)* | Prefer `Valencia metro` / Metrovalencia look; avoid Madrid/Barcelona if logos are obvious |
| **E1** | Dense tourist / city-centre street (contrast only) | `Valencia old town street` — **2s max** in hero cut |
| **G1** | Turia / river-park nature | `Jardin del Turia` / Valencia river park |
| Generic | Hands on blueprint *(only if you don’t shoot B3)* | Prefer live B3; stock blueprints look like ads |

**Stock grading rule:** Match colour to A-roll (slightly mute; no orange “travel influencer” grade). Keep stock inserts ≤2–3s. Soft ambient under — never stock music swells.

**Licence:** Buy **commercial / advertising** rights for web + paid social + B2B email. Prefer 4K. Avoid “editorial only.” Save invoice + licence PDF in this folder under `licences/` when purchased.

**Do not buy as stock:** Fake happy investors, luxury rooftop pools, “signing the deal,” euro cash close-ups, generic Spanish fiesta — all poison for a skeptic audience.

## Part I — A-roll (Uriel talking)

Record **full script thrice** at Primary A-roll location. Best audio wins.

### A1 — Primary interview (Riba-roja site)

| Shot ID | Framing | Direction | Notes |
|---|---|---|---|
| **A1.1** | Medium close-up (chest up), slight off-centre | Eye line just off lens (or direct lens if Uriel can hold it) | Soft sun or open shade. Dirt / fencing / structure softly out of focus behind him. |
| **A1.2** | True close-up (eyes to mouth) | Same angle as A1.1 | Safety for cutaways on honesty lines |
| **A1.3** | Medium (waist up) | Room for walking → stop → talk | Only if site is quiet; else skip |
| **A1.4** | Profile / ¾ | Uriel looking toward site | For cut into “this is not Valencia centro” |
| **A1.5** | Wide establishing with Uriel small in frame | Hold 5s, no speech | Context: suburban scale |

**Script coverage map**

| Script block | Prefer shot |
|---|---|
| Heart (0:00–0:20) | A1.1 |
| Honesty (0:20–0:45) | A1.1 → insert A1.2 on “not Valencia city centre” and “not a bank guarantee” |
| Stakes (0:45–1:05) | A1.1 |
| Door / CTA (1:05–end) | A1.1 direct to lens; hold 2s after last line |

### A2 — Backup interview (clean room)

Same framing as A1.1 / A1.2 if site wind / trucks kill audio. Neutral wall or window light. Use only if A1 audio fails — don’t mix aesthetics mid-sentence unless matchable.

### A3 — Pickup lines (slate each)

Record these lines clean, isolated, for edit flexibility:

1. “It’s Riba-roja — Metro Line 1, airport close, suburban, real.”  
2. “It is also not a bank guarantee.”  
3. “Reply and tell me which fear is loudest right now.”  
4. Name + title: “Uriel Nabel, founder of El Fortín.”

## Part II — B-roll (picture for words)

Use **sparingly** in the 90s cut (aim ≤25% of runtime). Extra B-roll banks secondary ads / fear-branch videos.

### Block B — Riba-roja site (truth of the asset)

| Shot ID | Description | Duration seek | Syncs with |
|---|---|---|---|
| **B1** | Exterior street plaque / address Carretera or Camino Valencia · Riba-roja | 3–4s | Honesty |
| **B2** | Wide of plot / structure / fencing — reality of a development, not a render | 4–5s | Stakes |
| **B3** | Hands: plans, tablet, or printed planos on site table | 3s | Stakes |

## Part III — Audio & coverage rules

| Do | Don’t |
|---|---|
| Lav + camera backup on every A-roll take | Rely on on-camera mic alone outdoors |
| Room tone / site ambience 30s at each location | Loud music bed under honesty lines |
| Clap sync at head of each take | Endless “one more for the gram” after he’s drained |
| Cue cards off-lens for Uriel | Ask him to memorize every comma |

**Wind:** If site is blown out, finish A2 indoor same day. Don’t fight weather for vanity.

## Part VI — Talent notes for Uriel

- Wardrobe: soft earth / navy / linen — no logo polo, no suit-and-tie “banker.”  
- One watch / wedding ring OK. No prop headphones.  
- Between takes: walk the site in silence once with camera on him (usable).  
- If he laughs or restarts on a true line — **keep the take**; honesty beats clean.

## Day wrap deliverables (ask editor for)

1. Hero cut 70–90s (16:9) + 9:16 crop  
2. Clean A-roll select reel  
3. B-roll selects bin sorted Block B / C / D / F  
4. 5–10 portrait stills  
5. Optional: 15s mute teaser for LinkedIn (face + one honesty line + CTA text)

When this day is in the can, you have the face for Strategy 01 — and enough truth pictures that the teaser PDF never has to carry the emotional load alone.
