# Strategy 01 — Heart → Face → Micro-loop

**Goal:** Reach skeptical capital (especially Northern European / finder-mediated investors) without leading with brochure yield — then create a tiny feedback loop so strangers behave a little more like people you’re sitting across from.

**Why this exists:** One-to-one, you sell with reaction and years of attention craft. Online has no face to read. This system **pre-answers the insult**, then **asks for their next punch**, so you get a signal before you dump the data room.

---

## Psychology (the only rules that matter)

1. **Don’t lose them is more important than finding them.** First contact should lower shame and increase “this person won’t lie to me.”
2. **Heart before math.** Yield confirms; it doesn’t open. Open with why the building exists and what *you* lose if you fail.
3. **Name their fear first.** “You’re right that Riba-roja isn’t Valencia centro” beats “exciting lifestyle hub.”
4. **Heart ≠ soft music.** For this audience, warmth is loyalty + competence: candid risk + clean documents.
5. **Simulate the 1:1 loop.** CTA is not “unlock the brochure.” CTA is “tell me which fear is yours.”

---

## The system (sequence)

```
Hook video (70–90s)
    → Choose-your-fear CTA (email reply or 4 buttons)
        → Matching short reply / 45s clip
            → Investment teaser one-pager (on request)
                → Data room (Folder 03 first when counsel engages)
                    → Live 1:1 (where you’re already strong)
```

**Distribution fit**

| Audience | First asset |
|---|---|
| End investor (cold-ish) | Founder video in first line |
| Finder / agent | Short video + B2B email (`b2b/outreach-cold-email-template.md`) |
| Warm referral | Personal video note + “who fits this profile?” |

## Success looks like

Someone replies with a specific worry (“who guarantees the guarantor?”) — not “looks nice, send brochure.” That’s the loop starting. You win the next minute; then you sell.
