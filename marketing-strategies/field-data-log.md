# Field Data Log

Every real-world observation gets logged here with a stable ID (F1, F2, …). Strategy docs cite these IDs. This is the project's only cure for "no data to anchor on" — observations in, decisions traced.

**Rules:** log verbatim-as-possible, date it, name the source, tag confidence. Never round an anecdote up to a statistic — an F-entry is a signal, promoted to a decision only when it repeats or is cheap to act on.
